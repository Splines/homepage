An MCP server for Claude Desktop. It automatically installs a small bridge in Cavalry, such that the agent can read the current scene state and execute code in your project. The MCP server also bundles the entire Cavalry user docs including the JavaScript API, such that you get precise answers.

This project is not affiliated with or endorsed by Cavalry, nor by Anthropic. All prompts were tested with Sonnet 5 (medium effort).

Get Unstuck

You're the artist with taste and ideas. It's frustrating when you can't get them out of your head the way you want, e.g. because you're new to Cavalry or just human and don't know every functionality of a complex program. With the CavalryMCP, you can ask Claude to help you with your project, while remaining in full control.

Prompt

Use the CavalryMCP. I have a bouncing ball animation using Forge Dynamics. But right now, the ball only bounces off the ground (composition bottom). Instead, I want it to bounce off the rectangle named "Ground". Fix that and also tell me how I could have achieved that in the UI on my own.

~1m10s | ~ 850 Tokens
Started with the scene that had the bouncing ball and the rectangle named "Ground" defined. A basic Forge setup for the bouncing ball was in place, but the ground shape not added as body and no collision detection.

How to do it in the UI

  1. Select the Forge Dynamics layer, open its Attributes.
  2. Under Ground Mode, switch it to Off (Attributes panel, top-level settings).
  3. Drag the Ground layer from the Scene/Assets into the Forge Dynamics Bodies (shapes) attribute — or right-click Ground → Add Body → Add to Forge Dynamics.
  4. On the new Body entry for Ground, open its Body tab and change Body Type from Dynamic to Still (a Still body participates in collisions but doesn't move or fall).
  5. Scrub the timeline (or hit play)to re-simulate — the Ball should now bounce off the Ground rectangle's top edge instead of the composition's bottom edge.

Better Understand Cavalry

LLMs are also great for learning. You can ask Claude to explain how a certain feature works or how to achieve a certain effect. The MCP server gives Claude access to the current scene state and provides tools to search the bundled Cavalry docs.

Prompt

Use the CavalryMCP. Is there a way in Cavalry to automatically animate text paragraph by paragraph? E.g. some snappy, staggered reveal animation?

~25s | 760 Tokens

Yes — Cavalry has a built-in behavior made exactly for this: Auto-Animate, combined with Text's paragraph/line level splitting. Here's the recipe for a snappy, staggered paragraph-by-paragraph reveal:

Steps

  1. Create your Text Shape with each paragraph separated by a blank line (Cavalry treats a paragraph as text separated by an empty line).
  2. Select the Text Shape, and click Auto-Animate in the Shelf (this auto-checks Use Levels, since Text is a sub-mesh).
  3. In Auto-Animate's Animation tab, set:
    • Level Mode → Custom... with a Custom Level Range targeting Paragraph.
    • Opacity Mode → Fade Up for a reveal.
  4. In the Timing tab, check Time Offset so each paragraph is staggered automatically.

Prompt

Use the CavalryMCP. Unfortunately, I've lost the overview over my scene. Tell me what is going on in all these layers.

~20s | 870 Tokens

Here's the picture of your scene, reconstructed from the scene graph:

Concept: A particle-morphing animation that spells out a sequence of math symbols/words, one morphing into the next — like sqrt → pi → e → integral → nabla → partial → delta → approx → infty → in → equiv → smaller → bigger → sum.

Core building blocks

  • basicShape#1 "Particle" — the single source shape (a dot/particle) used by every duplicator below. Its fill color comes from colorArray#3 "Colors".
  • 14 Duplicators, one per symbol. Each one distributes copies of basicShape#1, is masked by its own editableShape (a vector shape of that symbol's glyph), and has its particle scale driven by an oscillator, giving a lively size-jitter per particle.

The morph chain
Each duplicator's output feeds into a blendSubMeshPositions node that blends it toward the next duplicator in the sequence, which in turn becomes a deformer on the next duplicator. This creates one continuous pipeline from sqrt all the way to sum.

Summary: It's a 14-stage particle text-morph rig, each stage a masked duplicator plus a blend transition to the next, all sharing one particle shape and one color source, with staggers/oscillators layered on top for organic timing and scale variation.

Installation

  1. Download the CavalryMCP.zip (a download link is sent to you by email after checkout).
  2. Add the MCP server to Claude Desktop's configuration (claude_desktop_config.json) as described in the included README.
  3. In Cavalry, navigate to Scripts > Show Scripts Folder and drag the bundled bridge script in-place, then run it once from Scripts > CavalryMCP Bridge with your project open.
  4. Restart Claude Desktop and ask it to use the CavalryMCP tools.

Usage

Start your prompt with "Use the CavalryMCP" (or simply enable the MCP server for the conversation) so Claude reaches for the scene-state and documentation-search tools instead of guessing.
